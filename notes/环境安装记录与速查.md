## 二、重要经验（这次踩过的坑）

1. **命令用 `python`，不要用 `python3`**。本机 `python3` 指向 Windows 商店的空壳（会直接失败），`python` 才是 D 盘的 Python。
2. **Windows 默认软件源（PyPI）只有 CPU 版 PyTorch**。GPU 版必须从 PyTorch 专用源装：
   - 实测清华 / 阿里云 / 中科大的 pytorch-wheels 镜像都不可用（404 或空页面）；
   - **上海交大镜像可用且速度 20MB/s**：`https://mirror.sjtu.edu.cn/pytorch-wheels/cu126/`
   - 方法：手动下载 `torch-2.9.1+cu126-cp312-cp312-win_amd64.whl`（2.4GB）和匹配的 torchvision wheel，然后本地安装。
3. **普通 pip 包用清华源加速**：`-i https://pypi.tuna.tsinghua.edu.cn/simple`
4. **yolov8n.pt 权重从 GitHub 下载很慢/失败**。改用 HuggingFace 国内镜像手动下载到工作目录：
   `https://hf-mirror.com/Ultralytics/YOLOv8/resolve/main/yolov8n.pt`
   权重文件放在当前工作目录后，yolo 命令会直接使用，不再联网。
5. **测试图片不用下载**：Ultralytics 安装包自带，路径 `D:\python\Lib\site-packages\ultralytics\assets\bus.jpg`。

## 三、常用命令速查

```bash
# 用预训练模型检测一张图（最常用）
yolo predict model=yolov8n.pt source=图片路径

# 用预训练模型检测整个文件夹
yolo predict model=yolov8n.pt source=图片文件夹路径

# 训练（官方小数据集，验证流程用，几分钟跑完）
yolo detect train data=coco8.yaml model=yolov8n.pt epochs=30 imgsz=640

# 训练自己的数据集（mydata.yaml 里写数据集路径和类别名）
yolo detect train data=mydata.yaml model=yolov8n.pt epochs=100 imgsz=640 batch=16

# 训练时指定用 GPU（默认就用，可省略）
yolo detect train data=coco8.yaml model=yolov8n.pt epochs=30 device=0

# 查看版本和环境信息
yolo version
```

## 四、结果文件去哪了

所有输出默认存在"当前工作目录"下的 `runs/` 文件夹：

```
runs/
├── detect/
│   ├── predict/          # 预测结果（第一次是 predict，之后 predict2、predict3…）
│   └── train/            # 训练结果
│       ├── weights/
│       │   ├── best.pt   # 训练中效果最好的模型（以后用它检测）
│       │   └── last.pt   # 最后一步的模型
│       ├── results.png   # 训练曲线（loss、mAP、精确率、召回率）——一定要看
│       └── confusion_matrix.png
```
