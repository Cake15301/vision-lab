## 第一章 先搞懂"目标检测"这个任务

### 1.1 图片在电脑里到底是什么

一张照片在电脑里不是"一张图"，而是一堆**数字**。

想象一张图被切成很多个小方格，每个小方格叫一个**像素（pixel）**。彩色照片里每个像素由三个数字组成，分别表示**红（R）、绿（G）、蓝（B）**三种颜色的亮度，每个数字在 0～255 之间。0 表示这个颜色完全没有，255 表示最亮。三种颜色按不同比例混合，就能调出任何颜色——这就是你手机屏幕能显示彩色照片的原理。

所以一张图片在电脑里就是：

```
一个 高 × 宽 × 3 的"数字盒子"
```

比如一张 640×640 的彩色照片，就是 `640 × 640 × 3 = 1,228,800` 个数字。这串数字就是电脑"看到"的全部信息。

### 1.2 让电脑"看图"要解决什么问题

**目标检测（Object Detection）** 要回答两个问题：
1. **图里有没有我关心的东西？**（比如：缺陷、色纱、标签）
2. **如果有，它在哪个位置？**

回答的成果是：在图上画一个**框（bounding box）**把目标圈起来，再在框旁边写上它的**类别（class）**（比如"毛刺""纤维环"）。

### 1.3 一个"框"由几个数字表示

一个框在数学上就是 4 个数，通常用下面两种写法之一：

- **(x, y, w, h)**：框的左上角坐标 + 框的宽 + 框的高；
- **(cx, cy, w, h)**：框的中心点坐标 + 框的宽 + 框的高。

坐标单位可以是像素（比如第 200 列、第 150 行），也可以归一化成 0~1 的小数（除以图片宽度/高度），后面会看到标注时常用归一化。

再加上两个信息：
- **置信度（confidence）**：模型说"我有多确定这里有个目标"，取值 0～1；
- **类别概率**：它属于每一类的可能性。

所以检测的输出，就是"一堆框 + 每个框的类别 + 每个框的置信度"。

## 第二章 深度学习是怎么让电脑"看懂"图的

### 2.1 传统方法 vs 深度学习

**传统方法**：人手工设计规则。比如"缺陷的地方颜色比较暗，灰度值低于 50 就报警"。缺点：换一种光照、换一种缺陷就失灵，规则写不完。

**深度学习**：不给电脑写规则，而是**给它看大量"图 + 标准答案"**，让它自己总结出规律。就像教小孩认猫：不用解释"猫有尖耳朵"，只要让他看几百张猫的照片，他自然就学会了。

### 2.2 神经元、权重、网络

深度学习的基本单元叫**神经元（neuron）**，学名也叫"感知机"。一个神经元做的事很简单：

```
输出 = 输入1 × 权重1 + 输入2 × 权重2 + ... + 偏置
```

**权重（weight）** 就是每个输入的重要性，是网络自己"学"出来的数字，一开始是随机的，训练过程中不断被修改。**偏置（bias）** 是加的一个调节项。

把几百万个神经元按层堆叠、连起来，就构成了**神经网络（neural network）**。层数多就叫"深"，所以叫**深度学习**。

### 2.3 卷积：像盖章一样滑动

图片是二维数字格子，如果让每个神经元都看整张图，计算量爆炸。所以 CNN（卷积神经网络）用了**卷积（convolution）** 这个专门技巧。

**卷积核（kernel）** 是一小块数字模板，比如 3×3 大小（9 个数字）。操作方式：

1. 把卷积核盖在图片左上角；
2. 对应位置的数字相乘再全部相加，得到一个数；
3. 卷积核**向右滑动一格**（这个滑动步长叫 **stride**，步长 1 就是每次移 1 格），再算一遍；
4. 直到扫过整张图，得到一张新的"小一号的图"，这张图叫**特征图（feature map）**。

你可以把它想成用"印章"在图上盖章：不同的印章（卷积核）提取不同的模式。有的印章专门"挑出竖线"，有的专门"挑出横线"，有的专门"挑出颜色突变"（那通常就是边缘）。

所以卷积层的作用是：**自动学习一堆"印章"，每种印章负责识别一种局部特征**。

### 2.4 特征图：逐层抽象

网络第一层的特征图存的是"边缘、线条"；
第二层把线条组合成"纹理、小图案"；
第三层组合成"局部部件"；
越往后越抽象，最后几层能表示"这是一片毛刺区域"这种高级概念。

这就是"特征金字塔"的雏形：**浅层特征图分辨率高、信息细，适合找小目标；深层特征图分辨率低、语义强，适合找大目标**。后面 YOLO 的多尺度检测就用到了这一点。

### 2.5 池化 / 下采样：把图变小

网络每过几层，会把特征图缩小（比如 640×640 → 320×320 → 160×160……）。这个操作叫**下采样（downsampling）**，常见做法叫**池化（pooling）**——比如"最大池化"就是每 2×2 的格子只留最大的那个数。

好处：
1. 图变小，计算量变小；
2. 每个神经元"看"的范围相对变大了（感受野变大），能看到更大的上下文。

### 2.6 从特征到结论：检测头

网络前半段（**Backbone，主干网络**）负责提取特征；最后面一小部分（**Head，检测头**）负责把特征"翻译"成结论：这个位置有没有目标、目标框多大、属于哪一类。Backbone + Head 合起来就是一个完整的检测网络。

## 第三章 YOLO 是什么

### 3.1 名字的由来

**YOLO = You Only Look Once**，中文"你只看一眼"。

2016 年，华盛顿大学的 Joseph Redmon 等人提出了 YOLO。名字就说明了它的核心卖点：**整张图只"看"一遍，就直接给出所有目标的位置和类别**。看一眼就出结果，所以特别快。

### 3.2 检测两大流派

**两阶段（two-stage）**，代表是 R-CNN 家族（Faster R-CNN）：
- 第一步，先用一个"候选框生成器"（RPN，区域建议网络）在图上粗筛出几千个"可能有目标"的区域；
- 第二步，对每个候选区域再做一次仔细的分类和位置精修。
- 像"先圈出可疑区域，再逐个审问"，准但慢。

**单阶段（one-stage）**，代表就是 YOLO、SSD：
- 不做粗筛，直接把整张图喂进网络，网络一次性输出所有框和类别。
- 像"全班扫一眼，直接点名"，快，精度以前略逊，现在（v5/v8）已经追平甚至反超。

### 3.3 YOLO 的核心理念

把"检测"当成一个**回归问题（regression problem）**：输入一张图，输出一堆数字（框的坐标、置信度、类别概率）。既然是数字，就可以用神经网络"一次前向传播"（图从网络入口走到出口，走完一遍）直接算出来。

因为不用分两步、不用来回倒腾，YOLO 天生快，特别适合**实时**场景——生产线上一张接一张地检测。

## 第四章 YOLO 是怎么工作的（核心中的核心）

### 4.1 把图片切成网格

YOLO 的做法非常巧妙：**把输入图片平均切成 S×S 个网格（grid cell）**。比如 640×640 的图切成 8×8，就是 64 个小格子，每个格子 80×80 像素。

约定规则：**每个格子只负责"中心点落在这个格子里的物体"**。也就是说，如果一只鸟的中心恰好落在第 3 行第 5 列的格子里，那么这个格子负责检测它；就算鸟的身体占了周围三个格子，也只有中心所在的那个格子负责。

### 4.2 每个格子输出什么

每个格子输出一组数，包含三类信息：
1. **若干候选框**：这个格子预测的几个框（中心坐标偏移、宽、高）；
2. **每个框的置信度**：这个框里"有没有物体"以及"框得准不准"；
3. **类别概率**：这个格子里的物体属于每一类的概率。

（在早期 YOLOv1 里，每个格子固定预测固定数量的框，比如 2 个；现代版本用锚框或 anchor-free，见 4.4。）

### 4.3 框的坐标怎么表示

假设图片被切成了网格，网络不会直接输出"像素坐标"，而是输出**相对格子的值**：

- 物体中心在格子内的偏移量（0～1 之间的小数，表示偏离格子左上角多远）；
- 框的宽高相对整张图的比例。

这样输出永远是 0~1 之间的小数，方便网络学习，也方便换算回真实像素。

### 4.4 锚框（anchor box）：给模型"参考框"

早期 YOLO 有个问题：物体的形状多种多样（人又高又瘦，汽车又宽又扁），让网络直接预测宽高很难。

解决思路叫**锚框（anchor box）/ 先验框（prior box）**：
- 训练前，先统计数据集里所有标注框的宽高比，聚类出几种"典型形状"（比如 k=9 种）；
- 网络不是从头猜框，而是**以这几种典型框为"起点"，只预测"和起点差多少"**（偏移量）；
- 就像猜房价时先给个基准价，再预测加减多少，比从零开始猜容易得多。

（YOLOv8 更进一步，去掉了锚框，直接预测"目标中心点的概率分布"再推出框，叫 **anchor-free**，更简单更快。你只要知道"锚框=预设参考框"这个概念就行。）

### 4.5 多尺度检测：大小目标都能抓

前面说过，浅层特征图适合小目标，深层特征图适合大目标。YOLO 从 v3 开始用**特征金字塔（FPN）**：把不同深度的特征图拿出来，**同时**在上面做检测。

- 大物体 → 用深层、语义强的粗特征图（格子大）；
- 小物体 → 用浅层、分辨率高的细特征图（格子小）。

这就像：站远了看整体（深特征），走近了看细节（浅特征），两套判断都做，最后汇总。

### 4.6 输出到底长什么样（一个具体例子）

假设：输入 640×640，切成 8×8 网格，每格预测 3 个锚框，数据集中有 2 类目标（比如"毛刺""纤维环"）。

则网络输出的"张量"（可以理解成一个多维数字盒子）尺寸是：

```
8 × 8 × 3 × (4 + 1 + 2)
```

拆开看：
- 8×8：网格数；
- 3：每个格子预测 3 个锚框；
- 4：框的坐标（cx, cy, w, h）；
- 1：置信度；
- 2：两个类别的概率。

总共 8×8×3×7 = 1344 组数字，网络一次算完。这就是"只看一眼"——**所有格子的预测在一次前向传播里同时完成**。

### 4.7 后处理 NMS：去掉重复的框

预测完了，问题来了：同一个物体往往被好几个格子、好几个锚框同时命中，会出现一堆重叠的框，如图上同一只鸟被框了 5 次。

解决工具叫**非极大值抑制（NMS, Non-Maximum Suppression）**，流程：

1. 先按置信度把所有框排序；
2. 取置信度最高的框，保留；
3. 看它和其他框的**重叠程度（IoU，见 6.1）**，把重叠超过阈值的框全部删掉（因为它们大概框的是同一个物体）；
4. 在剩下的框里重复 2、3，直到处理完。

最后每个物体只剩一个最自信的框。（你读的论文一里把 NMS 改成 Soft-NMS——重叠框不直接删，而是降分，减少把真目标误删的风险。）

## 第五章 训练一个 YOLO 需要什么

### 5.1 数据：图片 + 标注

训练需要"图 + 标准答案"。标准答案就是人工标注的框，叫 **Ground Truth**（真实值）。

标注工具：labelImg（画矩形框）、Labelme（画多边形）。标注完导出成文件，YOLO 的常见格式是一个 txt 文件对应一张图，每行：

```
类别编号  cx_norm  cy_norm  w_norm  h_norm
```

比如 `0 0.512 0.344 0.120 0.081`，意思是第 0 类，中心在 (0.512, 0.344)，宽 0.12、高 0.081（都是相对图片宽高的比例，所以叫**归一化**）。

### 5.2 划分数据集

把数据分成三份（常见比例 8:1:1 或 7:2:1）：
- **训练集**：用来学，网络主要靠它调参数；
- **验证集**：训练过程中用来"期中考试"，监控模型有没有越学越差，也用来调超参数；
- **测试集**：全部训练结束后用来"期末考试"，检验真实水平。测试集里的图模型**从没见过**，所以最能反映实战能力。

### 5.3 损失函数：怎么衡量"猜错多少"

网络每次猜完，要和标准答案对比，算一个"错多少"的数，这个数叫**损失（loss）**。损失函数就是算这个数的公式。YOLO 的损失由几部分组成：

- **框位置损失**：预测框和真实框贴得有多不准（用 IoU 相关的公式衡量）；
- **置信度损失**：该有物体的格子有没有自信、不该有的有没有乱报；
- **分类损失**：类别猜得对不对（常用**交叉熵**，它衡量"预测概率分布"和"真实类别"的差距）。

总损失 = 三个部分加权求和。**训练的目标就是让总损失越来越小**。

（你读的论文三里提到"平衡交叉熵损失"：当背景像素远多于边缘像素时，普通交叉熵会让网络偷懒——全猜背景也错不了多少，所以给少数类加权，逼它认真学边缘。）

### 5.4 优化器与梯度下降：怎么调参数

知道了"错多少"（损失），怎么改参数让下次错得少？

方法是**梯度下降（gradient descent）**：数学上可以算出"每个参数往哪个方向调、调多少，损失会降得最快"，这个方向叫**梯度**。更新规则：

```
新参数 = 旧参数 − 学习率 × 梯度
```

- **学习率（learning rate）**：每次迈步的大小。太大→步子迈过头，模型震荡不收敛；太小→走得太慢，学不完。通常从 0.01 或 0.001 起步。
- **优化器（optimizer）**：具体的梯度下降实现方式，常见 **SGD**（朴素版）、**Adam**（聪明版，自动调步长，新手用它最省心）、**AdamW**（Adam + 权重衰减，YOLOv8 用这个）。
- **反向传播（backpropagation）**：从网络最后一层往前一层层算梯度、更新参数的技术，是深度学习的引擎。

### 5.5 epoch、batch、iteration

- **batch（批）**：一次喂给网络多少张图。比如 batch=16，就是一次看 16 张。太小→学得抖，太大→显存不够（GPU 内存）。
- **epoch（轮）**：把整个训练集完整过一遍叫 1 个 epoch。比如训练集 8000 张、batch=16，那 1 个 epoch = 500 次 batch。
- 论文里说"训练 80 个 epochs""迭代 200 次"，就是让模型把数据反复学这么多轮。

训练过程你会看到 loss 曲线：开始高，慢慢下降，最后趋于平稳（这叫**收敛**）。如果 loss 一路下降但验证集表现反而变差，就是**过拟合**了（背答案了）。

### 5.6 防止过拟合：数据增强

模型参数很多，训练数据少，就容易"背答案"——训练集上满分，新图就翻车。

对策之一是**数据增强（data augmentation）**：训练时每张图随机做旋转、翻转、缩放、调亮度、加噪声、裁剪，等于 1 张图变出很多"长得不一样但答案相同"的样本，逼模型学本质而不是背图。你读的四篇论文全用了这招（第1篇 3640 张增强到 7280 张，就是翻倍扩容）。

### 5.7 迁移学习：站在巨人肩膀上

从零训练一个检测模型，需要海量数据和好几天 GPU 时间。好在有**预训练权重（pretrained weights）**：官方（Ultralytics 等）已经在几百万张的公开数据集（ImageNet、COCO）上把网络练好了。

**迁移学习（transfer learning）** = 拿别人练好的权重当"起点"，在自己小数据集上再练一会（**微调，fine-tune**）。YOLOv8 训练时写 `model=yolov8n.pt` 就是加载官方预训练权重——所以论文里几百张图就能训出 99% 的精度，全靠这个。

## 第六章 怎么评价一个 YOLO 好不好

### 6.1 IoU：框贴得有多准

**IoU（Intersection over Union，交并比）** = 预测框和真实框的**交集面积 ÷ 并集面积**。

```
IoU = 两框重叠面积 / 两框覆盖的总面积
```

- IoU = 1：完全重合（完美）；
- IoU = 0：完全没重叠；
- 通常认为 IoU ≥ 0.5 就算"检测到了"。

### 6.2 置信度阈值：多自信才算数

模型会输出一堆候选框和置信度。设定一个**置信度阈值（confidence threshold）**，比如 0.5：低于 0.5 的框直接丢掉。阈值设高→漏检多；设低→误报多。实际使用时要权衡。

### 6.3 精确率和召回率

先把预测结果分成四类（这就是论文里 TP/FP/FN 的意思）：

| 名称 | 含义 | 通俗说法 |
|------|------|---------|
| **TP**（真阳性） | 真目标，被正确框出 | 该抓的抓到了 |
| **FP**（假阳性） | 不是目标，被错误框出 | 抓错了 |
| **FN**（假阴性） | 是真目标，但没框出来 | 漏抓了 |
| **TN**（真阴性） | 不是目标，也没框出 | 正确地没管 |

两个核心指标：

```
精确率 Precision = TP / (TP + FP)      → 抓出来的里面，多少是真目标（查得准）
召回率 Recall    = TP / (TP + FN)      → 真正的目标里，抓到了多少（查得全）
```

直觉：精确率低 = "狼来了"太多（乱报）；召回率低 = "漏网之鱼"太多（该报没报）。两者经常此消彼长——框得越"贪婪"召回越高但误报越多。

### 6.4 AP：一张图看完"准"和"全"

只报一个数不公平，所以有了 **AP（Average Precision，平均精度）**：改变置信度阈值，得到一系列（精确率, 召回率）点，连成一条**PR 曲线**，曲线下的面积就是 AP。

- AP 越接近 1，说明无论阈值怎么调，"既准又全"；
- 相当于把"查得准"和"查得全"的权衡过程画成一条线，再用面积打分。

### 6.5 mAP：所有类别的平均

**mAP（mean Average Precision，平均精度均值）** = 把所有类别各自的 AP 取平均。

```
mAP = (AP_毛刺 + AP_纤维环 + AP_稀疏) / 3
```

这就是你论文里反复见到的数字：第1篇 mAP 92.7%，第2篇 99.5%。**mAP 是检测任务最重要、最常用的总评分。**

（日常还会看到 mAP50、mAP50-95：mAP50 是"IoU≥0.5 算检测到"时的 mAP；mAP50-95 是把 IoU 从 0.5 到 0.95 每隔 0.05 算一个 mAP 再平均，更严格，常用在 COCO 数据集上。）

### 6.6 速度指标：快不快

- **FPS（帧每秒）**：每秒能处理多少张图。论文四里"实时检测速度 32.3 帧/s"，意思是一秒能看 32 张图，够实时。
- **FLOPs**：一次推理的浮点运算次数，衡量**计算量**。FLOPs 越小，跑得越快、越省电（论文二里 15.8G→7.7G）。
- **参数量（Params）**：网络里要学习的数字的个数，衡量**模型规模**。越小越适合塞进便宜设备（论文二里 703万→456万）。

产线选模型就是"精度、速度、成本"三者权衡：YOLOv8n 最小最快，YOLOv8x 最大最准。

## 第七章 YOLO 家族史（简要版）

| 版本 | 年份 | 重要改进 | 一句话 |
|------|------|---------|--------|
| YOLOv1 | 2016 | 开创：网格 + 一次回归直接出框 | "只看一眼"的诞生 |
| YOLOv2 | 2017 | 引入**锚框**、批归一化 | 框预测从"瞎猜"变成"基于参考框微调" |
| YOLOv3 | 2018 | **特征金字塔**多尺度检测、独立逻辑回归分类 | 小目标检测能力大幅提升，性价比封神 |
| YOLOv5 | 2020 | Ultralytics 公司化开发：C3 模块、SPPF、易用性极强 | **普及度最高的版本**，论文二就是改它 |
| YOLOv8 | 2023 | **去锚框（anchor-free）**、解耦头、C2f 模块、DFL 损失 | 当前主流，论文四用它，训练一行命令 |

你可能会困惑为什么没有 v6/v7 连着——因为 YOLO 发展中有多个团队分叉（v6 是美团团队、v7 是 v4 作者续作），Ultralytics 则走 v5 → v8 这条线。**你只要知道：Ultralytics 出品的 YOLOv5 和 YOLOv8 是最常用、文档最全的两个**，就够用了。

### 你们课题组论文里的 YOLOv5 改进，现在你能看懂了

论文二（色纱颜色识别）对 YOLOv5 做了三处改进，对照本章：

1. **轻量化 Backbone**：把主干网络的普通卷积换成 MobileNetV3 的"倒残差结构"和"深度可分离卷积"——就是换更省算力的"印章"，让网络更快，代价是精度略降；
2. **SE 注意力机制**：给网络加一个"重要程度调节器"，让它把注意力放在对颜色判别有用的特征通道上——把上面掉的精度补回来；
3. **加权特征融合**：原来融合不同层特征图只是简单拼接（Concat），现在每个来源学一个权重，按重要性加权——融合更聪明，收敛更快。

论文三的 SimAM 注意力同理：不增加任何参数（省硬件），但让网络更关注有用的神经元。

## 第八章 下周动手路线（回顾 + 细化）

1. **第1天**：`pip install ultralytics` → 跑 `yolo predict model=yolov8n.pt source=图片`，先看到"效果"。
2. **第2天**：跑官方小数据集训练 `yolo detect train data=coco8.yaml model=yolov8n.pt epochs=30`，看懂 loss 和 mAP 曲线。
3. **第3天**：自己拍 30~50 张图，labelImg 标注，导成 YOLO 格式（每行 `类别 cx cy w h`），8:1:1 划分。
4. **第4天**：写自己的 `data.yaml`（路径 + 类别名），训练 100 epochs。
5. **第5天**：用 `best.pt` 批量预测，看懂 results.png 里的 P、R、mAP 曲线。
6. **第6天**：n 和 s 两个模型各训一次做对比实验（这就是"消融试验/对比试验"的雏形）。
7. **第7天**：写一页总结，准备见导师。

### 常见报错速查

- `No module named 'torch'` → 没装 PyTorch，先 `pip install torch torchvision`（CPU 版也能跑，慢而已）；
- 显存不足（CUDA out of memory）→ 调小 batch（`batch=8` 改 `batch=4`）或换 `yolov8n` 更小模型；
- 训练完 mAP 很低 → 多半是标注错了（框没对齐目标）、类别编号错位、或图片太少；
- `labelImg` 打不开 → 用 Python 版：`pip install labelImg` 后命令行启动。
