# YOLO 使用指南（新手版）

> 目标：5 分钟内学会怎么"打开 YOLO、让它干活、看结果"。

## 一、先理解：YOLO 为什么没有图标

YOLO 不是像微信、Word 那样有窗口和按钮的软件，它是**命令行工具**——一个"会听话的程序"，你要通过**打字输入命令**来指挥它。

它实际安装在：`D:\python\Scripts\yolo.exe`

你不需要记住这个位置，因为桌面上已经有快捷入口了（见下一节）。

## 二、最快上手：双击桌面上的"YOLO终端.bat"

桌面上现在有一个 **`YOLO终端.bat`**，双击它，会弹出一个黑色窗口（这个黑窗口就是**终端/命令行**）。窗口里已经显示：

- 当前目录已自动进入 `D:\AI\zcode files\YOLO入门学习`（你以后的所有文件都放这里）
- 常用的命令提示

窗口最后一行是让你输入命令的地方（光标在闪烁）。**现在输入下面这行命令测试一下**（可以直接复制粘贴，黑窗口里**右键 = 粘贴**）：

```
yolo version
```

按回车，会显示 `8.4.128`——说明 YOLO 已经准备好为你工作了。

## 三、让它干活：三个常用操作

### 操作 1：检测一张图片（最常用）

```
yolo predict model=yolov8n.pt source=图片的完整路径
```

把"图片的完整路径"换成你电脑上真实存在的图片，比如：

```
yolo predict model=yolov8n.pt source=D:\我的照片\织物缺陷.jpg
```

路径带空格和中文都没关系，用引号包住即可：

```
yolo predict model=yolov8n.pt source="D:\AI\zcode files\YOLO入门学习\test.jpg"
```

跑完后终端会显示检测到了什么（如 `1 fabric_defect`），并告诉你结果保存位置。

### 操作 2：检测整个文件夹里的所有图片

```
yolo predict model=yolov8n.pt source=文件夹的完整路径
```

它会自动处理文件夹里的所有图片。

### 操作 3：训练模型（做你自己的检测器）

先用官方自带的小数据集练一次手（几分钟跑完，不需要你准备数据）：

```
yolo detect train data=coco8.yaml model=yolov8n.pt epochs=30 imgsz=640
```

`epochs=30` 表示训练 30 轮。训练完会在 `runs\detect\train` 里生成训练曲线和模型文件。

## 四、怎么查看结果

检测/训练的结果都保存在**你当时所在目录的 `runs` 文件夹**里：

```
D:\AI\zcode files\YOLO入门学习\runs\
├── detect\
│   ├── predict\          ← 检测结果图（第1次是predict，之后是predict2、predict3…）
│   └── train\            ← 训练结果
│       ├── weights\
│       │   ├── best.pt   ← 最好的模型（以后检测用它）
│       │   └── last.pt
│       └── results.png   ← 训练曲线图（loss、mAP 等）
```

在文件资源管理器地址栏输入 `D:\AI\zcode files\YOLO入门学习\runs` 按回车，就能打开这个文件夹。

## 五、Windows 上打开终端的方法（备用）

除了双击桌面脚本，你还可以手动打开终端：

- **方法一**：按键盘上的 **Win 键**，输入 `PowerShell` 或 `终端`，回车；
- **方法二**：按 **Win + R**，输入 `powershell`，回车；
- **方法三**：在文件夹空白处按住 **Shift 再点鼠标右键**，选"在终端中打开"（这样直接就在该文件夹里）。

打开后先进入工作目录（否则模型会下到别处）：

```
cd "D:\AI\zcode files\YOLO入门学习"
```

## 六、常见问题

| 问题 | 解决 |
|------|------|
| 提示 `No such file or directory` / 找不到图片 | 路径写错了。图片路径要写完整，从盘符开始（如 `D:\...`），且用引号包住 |
| 提示 `No module named` | 说明你在别的 Python 环境里，确认你用的是 D 盘 Python（本指南所有命令在"YOLO终端.bat"里运行即可） |
| 输入命令没反应 / 卡住 | 检查是不是在等待下载模型。把 `yolov8n.pt` 文件放在你所在的目录（工作目录里已有）就不会下载 |
| 窗口关了，结果还在吗 | 在。结果都保存为文件，随时可以打开看 |
| 想重复跑一次 | 终端窗口保留，按上方向键可以调出上一条命令，直接回车 |
| 训练时说显存不足 | 在命令末尾加 `batch=8`（把一次喂的图片数调小） |
