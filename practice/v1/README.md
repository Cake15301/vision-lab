# 零件检测仪 v1

一句话：**扫一个文件夹的零件图，逐件量尺寸、判合格，输出标注图和结果表**。
OpenCV 九站流水线，纯 Python，没用深度学习。

## 一、它解决什么问题

产线抽检靠人眼：慢、累、标准不统一。这个小工具把"量尺寸 ＋ 判合格"交给机器：
先拿一件确认合格的标准件做"首件标定"（量出它的面积和占空比当标称值），
之后每一件都跟标称值比，超出公差就判 NG，并在图上画框标出来。

## 二、架构（九站流水线）

```
零件图 (assets/in/*.png)
   |
   v
站1-2  读图，统一宽度 1000，转灰度
   |
   v
站3    中值滤波 5x5（去椒盐坏点）
   |
   v
站4    OTSU 自动二值化（零件白、背景黑）
   |
   v
站5    开运算 3x3（擦小白渣）
   |
   v
站6-7  找轮廓（只要最外层），面积 < 60 当灰尘扔掉
   |
   v
站8    量形：面积 / 外接框 / 占空比
   |
   v
站9    判定：跟标称值比，双闸（面积 ±5%，占空比 ±0.02）
   |
   +----------+----------+
   v                     v
标注图(绿框OK/红框NG)   结果表.csv
（都在 assets/out/）
```

## 四、参数为什么是这些值

每个参数都不是拍脑袋定的：先实测"同一件零件读数会晃多少"（重复性），
再把公差卡在"不误杀好件"和"不放过真缺陷"的中间：

| 参数 | 值 | 一句话依据 |
|---|---|---|
| TARGET_W | 1000 | 与 W06 实验同规格，历史数字能直接对账 |
| MEDIAN_K | 5 | 中值对椒盐噪声最有效；7 起开始啃零件边缘 |
| MORPH_K | 3 | 只擦比 3x3 小的白渣；5x5 起会把轮齿咬缺 |
| MIN_AREA | 60 | 灰尘最大 14.5、零件 186121，取中间空档 |
| TOL_AREA | ±5% | 实测波动 0.17% 的 29 倍，且小于偏小件的 -18.7% |
| TOL_FILL | ±0.02 | 实测波动 0.0012 的 16.7 倍 |

完整推导、实测数据和"换相机必须整表重标"的警告见 [参数依据.md](参数依据.md)。
